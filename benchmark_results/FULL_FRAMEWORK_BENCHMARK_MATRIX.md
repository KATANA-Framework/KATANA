# Full Framework Benchmark Matrix

Combined report for HTTP (`hello`, `compute`) and SQL Stage 4 scenarios across KATANA, actix-web, axum, ntex, drogon, and fastapi.

## Method

- HTTP: one live server at a time, `workers=4`, `repeats=5`, `warmup=1`, `median` aggregation, shared `wrk` Lua scripts.
- SQL: one live server at a time, shared PostgreSQL fixture, `workers=4`, `seed=4096`, `repeats=5`, `warmup=1`, `median` aggregation.
- This is still same-host benchmarking, not a split load-generator/server setup.
